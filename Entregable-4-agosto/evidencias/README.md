## Mapa y wireframes

- `mapa-del-sitio.svg` — diagrama vectorial fuente.
- `mapa-del-sitio.png` — exportación PNG para PDF.
- `mapa-del-sitio-preview.html` — fuente de previsualización/exportación.
- `wireframes/wireframes.html` — fuente editable sin dependencias externas; selecciona cada vista con el parámetro `?frame=`.
- `wireframes/01-inicio-desktop.png`, `02-inicio-mobile.png`, `03-sobre-mi-desktop.png`, `04-servicios-desktop.png`, `05-servicios-mobile.png`, `06-portafolio-desktop.png`, `07-showcase-desktop.png`, `08-terminos-desktop.png`, `09-terminos-mobile.png` — nueve vistas de baja fidelidad.

Los wireframes expresan jerarquía y distribución; las etiquetas “propuesta” distinguen acciones o índice local que no se verificaron en el sitio publicado.
